# 🏨 Roomly - Room Booking System

Roomly adalah aplikasi berbasis web untuk manajemen pemesanan kamar atau resource secara efisien. Dibangun menggunakan **Laravel 11**, aplikasi ini menyediakan fitur lengkap mulai dari sisi pengguna hingga manajemen admin.

## ✨ Fitur Utama

- **Sistem Autentikasi**: Login dan Register untuk User dan Admin.
- **Manajemen Profil**: Pengaturan data diri, metode pembayaran (Kartu & E-Wallet).
- **Pemesanan (Booking)**: Pencarian resource/kamar dan proses booking yang terintegrasi.
- **Dashboard Admin**: Monitoring pesanan, manajemen data kamar, dan laporan keuangan.
- **Notifikasi Email**: Konfirmasi booking otomatis yang dikirimkan ke pengguna.
- **Responsif**: Tampilan yang optimal di berbagai perangkat.

## 🛠️ Teknologi yang Digunakan

- **Backend**: Laravel 11 (PHP 8.2+)
- **Frontend**: Blade Templating, Vanilla CSS, Vite
- **Database**: MySQL / MariaDB
- **Tools**: Composer, NPM
